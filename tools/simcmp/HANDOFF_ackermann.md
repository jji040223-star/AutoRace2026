## 왜

`drive_mode: diff` (기본) 로 그대로 남기고 `drive_mode: ackermann` 일 때만 바뀜.

- 시뮬은 동시에 10 개까지, 묶음엔 보기 창 하나

## 바꾼 것 (91fe68a)
1. `sim2d.py` — `drive_mode: ackermann`: limo_base 흉내 (r = v/w, |r| ≥ `ack_min_radius` 0.47, 조향 = atan(L/r), L 0.2,
   조향 지연 `steer_tau` 0.08 s, v = 0 & w ≠ 0 이면 최대 조향만 하고 안 돎). 모델은 base_link 중심 자전거 모델 (뒷축 기준 아님)
2. `mission_manager.py` M7 (`m7_ack_step`): 제자리 정렬·라이다 탐색(probe) 생략. 매 tick 곡률 11 개 × 11 개 (±1/`ack_plan_radius_m` 0.52)
   로 원호 두 개 (d1 0.25 m → d2 0.70 m) 를 굴려 `avoid.hits` 로 검사, 첫 원호가 안 닿는 것 중
   비용 = 2.0·|끝 옆 − 목표 차로| + 0.8·|끝 방향| + 3.0·(못 간 길이) + 0.05·|κ1−κ2| 최소. v = κ1 원호로. 차로 고르기·M2·종료는 기존 코드.
   막혀 후진할 때 차로 방향으로 펴며 (w = −k·ψ, |w| ≤ v/R) 후진
3. M8: 출구 맞추기 (`m8_exit`) 를 pure pursuit 전진으로 (시간 한도 2 배), 막힘 후진을 목표 틈 쪽으로 조향.
   원호 후보 선택 (`m8_ack_arcs`) 은 만들었지만 결과가 나빠 **끔** — 통로 주행은 기존 틈 가운데 추종 (v=0 이면 w 만 나가서 안 돎 → 막힘 감시 → 조향 후진)
4. `parking_controller.py`: ALIGN 목표 = 칸 가운데 − `ack_park_radius_m` 0.50 (빈 칸 찾을 때 이미 지나 있어 곧게 후진) →
   ARC_IN (전진 원호, r = Δu / (1 − sin θ) 로 매 tick 다시, ≥ 0.47) → MEASURE (아커만은 옆 오차 커도 돌아 나오지 않음) → ENTER → CHECK → HOLD →
   EXIT (들어간 만큼 후진) → ARC_OUT (후진 원호, r = d / (1 − cos θ)) → DONE
5. `traffic_light.py`: 첫 정지선(서행 구간, 신호등 1.65 m 앞)을 지나면 다음 선(횡단보도, `light_beyond2_m` 0.75) 기준으로 예상 거리.
   (오늘 M1 을 횡단보도 정지선에 서도록 바꾼 것과 짝 — diff 에도 해당)
6. `cone_layouts.py` curvy 0.18 / 1.8

## 열린 문제 (같이 봐 줬으면 하는 것)
1. **주차 실제 회전 반경**: 계획 0.50 m. 실차 최소 반경이 0.65 m 넘으면 원호 끝이 칸 선 밖 (계산: 0.60 → 여유 4 cm, 0.65 → −1 cm, 0.80 → 옆 LIMO 닿음).
   안 A: M7·M8 에서 최대 조향 원호 때 IMU wz / v 로 실제 반경을 재서 주차 시작 위치를 그만큼 당김.
   안 B: 원호 뒤 옆 오차 > 8 cm 면 앞뒤 보정 — 단 매 움직임 전 쓸기 검사 (라이다 LIMO + 칸 선 + 반대편 노란 선 가상 벽), 닿으면 안 함, 최대 2 번.
   사용자 걱정: B 는 차선 밖·정차 LIMO 충돌 위험. → A 가 먼저라고 봄. 반론·빠진 위험?
2. **curvy 라바콘**: 0.18/1.8 은 이론 여유 6 cm (가운데선 반경 0.46). 매 순간 반응형 (틈 가운데 추종) 으로 충분한가, 통로 전체를 보고 곡률 제한 경로를 미리 계획해야 하나
3. **M7 원호 계획**: 비용 가중치·d1/d2 가 임의 값. 진입 때 14~15° 틀어진 자세 + 바로 옆 차로로 가야 하는 배치 (c3) 에서 끼었음. 시작 창 계산상 줄 간격 0.9 m 에서도 S 자 시작 가능 구간 0.30 m (5 cm 여유)
4. **시뮬 모델 한계**: 자전거 모델 기준점이 차 중심 (실제 LIMO 는 뒷축 기준, 뒷바퀴는 옆으로 안 미끄러짐) — 주차·M7 여유 계산이 실제와 몇 cm 다를 수 있음. 바꿔야 하나
5. M1 신호등 노드 기준선 변경 (5) 이 실차에서 서행 구간 정지선을 못 보고 바로 횡단보도 선을 본 경우 1.65 m 를 써 버리는 문제 — 처리 필요?
